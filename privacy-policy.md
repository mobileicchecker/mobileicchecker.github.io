**AP Scrap Rates Privacy Policy**

AP Scrap Rates values and protects your privacy. This Privacy Policy explains how we collect, use, and safeguard information when you use our application.

---

## Information We Collect

We use several Firebase and Google services that may automatically collect certain types of technical and usage-related information.

### 1. Firebase Analytics

Firebase Analytics may collect:

- Device information
- App usage events
- Session data
- Country/region information

This information is used only to improve app performance and user experience.

### 2. Firebase Cloud Messaging (Push Notifications)

Firebase Cloud Messaging (FCM) may collect:

- Device token
- Notification delivery information

This data is used only for sending app notifications, such as daily scrap rate updates.

### 3. Firebase Firestore Database

Our application uses Firebase Firestore to store and retrieve scrap rate information.

- Scrap item categories, names, and prices
- Price history
- App settings (such as last-updated timestamps)

This data is not tied to any individual user and is used only to display accurate, up-to-date rate information.

### 4. Firebase Crashlytics

Firebase Crashlytics may collect:

- Crash logs
- Device information
- App version
- Stack traces

Used only for fixing crashes and improving app stability.

### 5. Firebase App Check

Firebase App Check is used to help protect the app and backend services from abuse, unauthorized access, and automated traffic.

## IC Checker Feature

The app includes an IC (integrated circuit) code lookup tool.

- IC codes you search are checked against an internal detection database bundled with the app, and against a forbidden-codes list fetched from a public GitHub repository.
- Search queries and results are **not** stored, logged, or linked to you in any way.
- This feature can also read the searched text aloud using your device's built-in text-to-speech engine; no audio is recorded or transmitted anywhere.

---

## Premium Access (Key Activation)

The app supports an optional premium key system, distributed directly by AP Scrap Rates/MiC Solution to selected users.

If you choose to activate a premium key, we collect:

- Your device's Android ID (a non-resettable-by-you device identifier used to bind the key to your device)
- The name you enter at activation time (used only to identify who a key belongs to for support purposes)

This information is stored in our Firebase Firestore database and is visible only to app administrators. It is used solely to manage premium access (for example, activating, disabling, or expiring a key) and is not shared with any third party or used for advertising.

We do **not** collect, as part of this feature:

- Email addresses
- Phone numbers
- Passwords
- Location data
- Payment information
